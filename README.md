## 🚀 Overview

This project is a sophisticated **Interactive Curriculum Vitae** built with modern web technologies. It transcends traditional static resumes by offering a dynamic, responsive, and engaging user experience. Designed to mimic the layout of an A4 page, it provides a familiar yet enhanced reading experience, complete with smooth transitions, interactive charts, and bilingual support.

## ✨ Key Features

*   **📄 A4 Page Simulation**: A unique layout that respects the classic CV format while adding digital interactivity.
*   **🌍 Bilingual Support**: Seamlessly switch between **English** and **Spanish** versions to cater to a global audience.
*   **📊 Interactive Data Visualization**: Utilizes `Recharts` to display investment portfolios and skill metrics dynamically.
*   **📱 Fully Responsive**: Optimized for all devices, ensuring a perfect viewing experience on desktops, tablets, and mobile phones.
*   **⌨️ Keyboard Navigation**: Navigate through pages using arrow keys for an intuitive browsing experience.
*   **🎨 Modern UI/UX**: Built with **Tailwind CSS** for a clean, professional, and polished aesthetic.
*   **🛠️ Modular Architecture**: Component-based structure using **React** and **TypeScript** for maintainability and scalability.

## 🛠️ Tech Stack

*   **Core**: [React](https://reactjs.org/) (v18), [TypeScript](https://www.typescriptlang.org/)
*   **Build Tool**: [Vite](https://vitejs.dev/)
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
*   **Icons**: [Lucide React](https://lucide.dev/)
*   **Charts**: [Recharts](https://recharts.org/)

## 🏁 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

Ensure you have **Node.js** (v16 or higher) installed.

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/gonsaliyo7-alt/Gonzalo_Segura_CV.git
    cd Gonzalo_Segura_CV
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```

4.  **Open your browser**
    Navigate to `http://localhost:5173` (or the port shown in your terminal).
